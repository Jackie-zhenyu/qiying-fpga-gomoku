# 离线语音配置资料

本目录保存8条控制口令（C1～C8）和25条状态播报（D0～E8）的映射及离线工作簿生成工具。

| 文件 | 用途 |
|---|---|
| `word_map_CO006.csv` | 口令、播报内容、线上ID及帧格式 |
| `profile_CO006_DISABLED.json` | 默认禁用的离线配置模板，不是实物固件状态记录 |
| `documented_wire_ids.json` | 所用模块中文V3协议表的原有ID集合，用于离线避碰检查 |
| `build_co006_package.py` | 基于用户自行取得的厂商原始模板生成配置工作簿、CSV与JSON |

UART配置为115200 baud、8N1。命令帧为 `AA 55 00 ID FB`，播报帧为 `AA 55 FF ID FB`。口令数量和帧格式描述的是配置设计，不表示所有口令场景均已完成整机验收。

## 生成厂商格式工作簿

需要Python 3.9+，仅使用标准库。先自行取得厂商提供的 `命令词播报词协议列表V3_中文.xlsx`，然后在仓库根目录执行：

```text
python tools/voice/build_co006_package.py "命令词播报词协议列表V3_中文.xlsx"
```

工具校验受支持模板的SHA-256，保留前10条原有功能词条和工作簿其他部件，在新建的 `tools/voice/generated/` 中输出资料。可用 `--output` 指定另一尚不存在的目录。它不会覆盖原模板、连接厂商平台、操作串口、生成语音固件或刷写芯片。原始厂商模板和已生成固件不随本仓库发布。

生成资料仍需在厂商平台检查并制作适配固件；默认禁用、12秒播报间隔等字段是保守的配置模板值。电平转换、实际音频时长、实物固件以及UART行为应单独验证。语音模块5V供电不等于其UART逻辑电平为5V。

本次发布整理未执行生成工具或仿真。当前整机语音的已知边界见根目录README，不应将历史模板中的待制作状态或词条数量解释为当前实物的测试结论。
