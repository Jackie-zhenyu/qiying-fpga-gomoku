# 作品海报

- [poster.pdf](poster.pdf)：A3竖版，一页，约4.51MB。中文文字以PDF文本形式排版，可用于作品海报提交。
- [poster.png](poster.png)：海报预览图。

海报采用米白与深绿色，内容包括：

- 人机对弈与面向教学、日常练习的陪练定位。
- 1080P图像输入、10×10当前已测棋盘、4槽位存档和离线运行。
- 实体落子、视觉确认、AI推演、玩家代放并确认的四步交互流程。
- 摄像头、FPGA、显示器、按键、语音与Flash存储的系统组成。
- 观测与正式棋局分离、棋谱与现场照片绑定保存的设计特点。
- 人机对弈与历史回看的两张真实运行画面。

主视觉使用AI生成的人机交互概念插画，图下已标明“概念示意”，不是样机实拍。实际系统由摄像头识别实体棋盘，FPGA计算并显示AI应手位置，棋子由玩家代放。项目源码和具体使用边界见仓库根目录README。

底部两张实机画面来自项目原始演示视频的完整16:9帧，分别呈现AI目标提示和保存局面的棋盘/照片回看，未进行图内合成或修改。历史回看表示查看保存时刻的局面，不表示逐手回放或自动读档续下。

海报二维码及文字链接均指向 https://github.com/Jackie-zhenyu/qiying-fpga-gomoku 。
