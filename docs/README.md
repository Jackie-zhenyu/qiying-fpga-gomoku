# 作品海报

- [poster.pdf](poster.pdf)：A3竖版，一页，约2.51MB。中文文字以PDF文本形式排版，可用于作品海报提交。
- [poster.png](poster.png)：海报预览图。

海报采用米白与深绿色，突出人机对弈、面向教学与日常练习的陪练定位，并介绍实体视觉识别、本地计算、存档回看与离线运行。

主视觉使用AI生成的人机交互概念插画，图下已标明“概念示意”，不是样机实拍。实际系统由摄像头识别实体棋盘，FPGA计算并显示AI应手位置，棋子由玩家代放。项目源码和具体使用边界见仓库根目录README。

海报二维码及文字链接均指向 https://github.com/Jackie-zhenyu/qiying-fpga-gomoku 。
